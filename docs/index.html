What it does

Every manual task,
handled in one tool

Built by a program chair who got tired of doing the same things by hand every conference cycle.

✅
PDF Compliance
Checks every submitted PDF for page count, font embedding, double-blind compliance, column layout, and references. Drag in a ZIP and it processes the entire batch.
● Deterministic — no API call
📊
Review Statistics
Score distributions, reviewer calibration, high-variance papers, missing reviews, acceptance rates per track. Flags short or inconsistent reviews automatically.
● Deterministic — no API call
🔍
Conflict of Interest
Scans every TPC member × paper pair for name, email, and affiliation conflicts. Uses fuzzy matching, ROR database lookup, and optional AI expansion to catch edge cases.
● Deterministic — no API call
🔬
AI Screening
Reads each paper PDF and assesses novelty, state-of-the-art coverage, writing quality, and LLM-writing signals. Strictness is adjustable per dimension. Uses your own API key.
● Uses your LLM provider
⚖
Decisions
Synthesises the full review set for each paper into a calibrated accept/reject recommendation with rationale, strengths, and weaknesses. Exports to CSV or Excel.
● Uses your LLM provider
📅
Program Builder
Conversational AI interface that builds a full day-by-day schedule from your accepted papers. Sessions, keynotes, and breaks — all exportable as CSV.
● Uses your LLM provider
📋
Review Quality
Assesses each reviewer's text for completeness, score–text consistency, and technical depth. Flags reviews that need a follow-up message from the chair.
● Uses your LLM provider
📸
Camera-Ready Check
Verifies final author PDFs for author names, copyright notice, PDF eXpress stamp, and font embedding. Manual override per paper for edge cases.
● Deterministic — no API call
✉
Email Suite
Drafts every conference email — CFP, TPC invite, review reminders, acceptance/rejection, camera-ready instructions — pre-filled with your conference details.
● Uses your LLM provider

How it works

Up and running in under five minutes

01
Download & open
Single executable — no Python, no Node, no install wizard. Double-click and it opens in your browser.
02
Add your CFP
Upload your Call for Papers PDF. AI extracts deadlines, tracks, page limits, and formatting rules automatically.
03
Import your files
Upload the papers ZIP, review export, TPC list, and author list once. Every module reads from the same data.
04
Run what you need
Each module runs independently. Export results as CSV or Excel at any point.

About

Built by someone who
has been there

Prof. Florenc Demrozi is a Professor of Biomedical Engineering at the University of Stavanger. He has served on the technical program committees of IEEE ICC, GLOBECOM, ICMLCN, VTC, and others — and spent too many late nights manually checking PDFs, hunting for affiliation conflicts, and chasing reviewers.

Program Chair Copilot started as a personal tool to automate what didn't need to be manual. It grew into something worth sharing with the community that runs these conferences.

It runs entirely on your machine. Your data never leaves your computer except for the AI calls you choose to make — and even then, only the necessary content is sent directly to your own LLM provider using your own API key. No telemetry. No account. No server.
